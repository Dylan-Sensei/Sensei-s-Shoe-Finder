# Sensei's Shoe Engine
## Machine Learning de modelos de tenis
En este proyecto estoy creando un sistema de alimentación de tenis de carrera de diferentes plataformas para un modelo de recomendación de tenis propio que vive en `Goggle Sheets`
El razonamiento de este proyecto es utilizar `Python` y `Pandas` para realizar _scratch_ en las bases de datos donde caen los drops de tenis nuevos y así automatizar la recomendación de tenis.
Dividiré este proyecto en 5 `Sprints` donde en el 5to intentaré incorporar `IA` para mejorar el proceso
